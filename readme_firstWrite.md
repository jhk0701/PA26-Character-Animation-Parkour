# 캐릭터 애니메이션 : 파쿠르 시스템

## 개요
- 2026 펄어비스 여름 인턴십 기간동안 진행한 <b>캐릭터 애니메이션 파쿠르 시스템 연구</b> 프로젝트입니다.
- 본 프로젝트에서 3D 환경에서 캐릭터로 하여금 여러 유형의 지형을 인식하는 방법과 
캐릭터의 상태에 따라 어떤 모션을 재생할 것인지 선택하는 과정을 구현하는 것을 중점으로 진행했습니다.
- 진행 기간 : `2026.06.30 ~ 2026.08.20`
- 시연 영상 링크
    - 본 영상에서 사용된 리소스는 라이센스 준수를 위해 현 프로젝트 첨부되어 있지 않습니다.
- 툴
    - 사용 툴 : `Visual Studio 2019`, `Visual Studio Code`, `Blender 5.1`, 
    - 사용 라이브러리 및 패키지 : `DirectX 11`, `PhysX 5.5`, `vcpkg`, `imgui`, `spdlog`, `assimp`, `nlohmann-json`
