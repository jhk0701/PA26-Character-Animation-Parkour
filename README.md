# 캐릭터 애니메이션 : 파쿠르 시스템


## 일정
- 1주차 : 엔진 기반 준비
    - 씬, 액터, 캐릭터 등 기반 클래스
    - 모델 로드
    - 애니메이션 재생
- 2주차 : 애니메이션 시스템, 물리 엔진 적용, 입력 바인딩
    - 캐릭터 애니메이션 블렌드
    - 애니메이션 로코모션 상태머신 적용
    - 루트 모션 적용
    - 물리엔진 (physX) 적용
    - 입력 바인딩
- 3주차 : 파쿠르 애니메이션
    - 장애물 높이, 깊이 인식
    - 인식한 장애물에 대한 파쿠르 애니메이션 선택 및 출력
    - 파쿠르 애니메이션 위치 보정
- 4주차 : 파쿠르 프로토타입
    - 높이에 따른 장애물 파쿠르 처리
    - 평지 - 벽면 로코모션 간 상태 전환
- 5주차 : 파쿠르 시스템 보완
    - 어색한 부분 다듬기
    - 애니메이션 IK 구현
    - IK 활용 애니메이션 디테일 보정
- 6주차 : 복잡한 지형 애니메이션 처리 1
    - 벽면 중간에 지붕, 경사로, 철봉 나열된 환경
    - 파쿠르 애니메이션 처리
- 7주차 : 복잡한 지형 애니메이션 처리 2
    - 직각으로 만나는 벽면 간 이동 처리
    - 벽면에 뻗어 나온 줄, 기둥 환경 파쿠르 애니메이션 처리
- 8주차 : 마무리
    - 테스트 및 오류 수정
    - 미흡 사항 보완
